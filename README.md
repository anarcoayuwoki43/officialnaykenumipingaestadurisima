# Nay Kenu — sitio web estático

## Contenido
- `index.html`: página web con navegación por secciones y textos desplegables.
- `documentos/dos-hermanos-un-imperio-en-llamas.pdf`: documento aportado para la sección «Nuestra visión del pasado».
- `documentos/el-motin-de-los-mestizos-1567.pdf`: documento aportado para la sección «Historia».
- El logotipo está incrustado en el HTML para evitar errores de carga por rutas de imágenes.

## Publicar en GitHub Pages
1. Sube `index.html`, la carpeta `documentos/` y este README a la raíz de un repositorio.
2. En GitHub, abre Settings → Pages.
3. Selecciona desplegar desde la rama principal y la carpeta raíz.
4. Guarda los cambios y espera a que GitHub Pages publique el sitio.
